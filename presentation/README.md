# Slides

The slides of the IAEG 2026 talk, *An Open-Source Workflow for Creating Soft-Soil Engineering
Geological Models and Making Them Accessible in BIM*:
<https://bedrock-engineer.github.io/iaeg2026-soft-soil-egm/slides/>

`IAEG2026_Soft-Soil-EGM.html` is one self-contained HTML file, which GitHub shows as source. The
Pages workflow serves it as `slides/` beside the project's home page. Downloaded, it also opens
straight from disk in a browser. The arrow keys move between slides.
